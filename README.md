# Portfolio Website | sm1le-devops

Personal portfolio website built to showcase my journey, technical skills, and projects as a software engineering student and Fullstack Web Developer.

## 🚀 Overview
This project is a modern, responsive, and interactive portfolio designed to highlight my expertise in bridging Python-driven backends with intuitive frontend interfaces. It serves as a central hub for my professional profile, technical "arsenal," and live project demonstrations.

## 🛠 Tech Stack
- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Cloudflare Pages

## 🔑 Key Features
- **Interactive Bento Grid:** A custom-built, responsive layout showcasing technical skills, backend/frontend stacks, and soft skills.
- **Dynamic UI:** Smooth transitions and animations powered by Framer Motion.
- **Mobile-First Design:** Fully responsive layout optimized for seamless browsing on all devices.
- **Project Showcase:** Detailed views for highlighted works, emphasizing clean code and scalable architecture.
- **Interactive Elements:** Engaging mini-games/bubbles to enhance user experience and retention.

## 📂 Project Structure
- `/app` - Main application logic and routing.
- `/components` - Reusable UI components (Bento grid, FlipCards, InteractiveText).
- `/public` - Assets, images, and static files.
